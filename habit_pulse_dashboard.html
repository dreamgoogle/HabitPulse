☁️ Google Apps Script Webhook Sync
Automate direct pushes into a live Google Sheet

1. Open your Google Sheet and click Extensions → Apps Script.

2. Paste the script below, click Deploy → New deployment → Web app (Access: Anyone), and paste the URL above:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.clear();
  data.rows.forEach(function(row) { sheet.appendRow(row); });
  return ContentService.createTextOutput("OK");
}
